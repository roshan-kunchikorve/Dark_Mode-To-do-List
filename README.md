# 🌙 Dark Mode To-Do List

A simple, clean To-Do List web app with a built-in **Dark Mode** toggle. Add tasks, mark them complete, delete them, and switch between light and dark themes for comfortable viewing anytime.

## ✨ Features

- ✅ Add, complete, and delete tasks
- 🌗 Toggle between Light and Dark mode
- 💾 Tasks and theme preference saved locally (persist after refresh)
- 📱 Responsive design — works on desktop and mobile
- ⚡ Lightweight — built with plain HTML, CSS, and JavaScript

## 🚀 Getting Started

### Prerequisites
No installation needed — this project runs entirely in the browser. You just need a web browser (Chrome, Firefox, Edge, etc.).

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/Dark_mode_To-do-list.git
   ```
2. Navigate into the project folder
   ```bash
   cd Dark_mode_To-do-list
   ```
3. Open `index.html` in your browser
   - Double-click the file, or
   - Use a tool like VS Code's **Live Server** extension for auto-reload

## 📝 Usage

1. Type a task into the input box and press **Enter** or click **Add**.
2. Click a task to mark it as complete.
3. Click the delete icon to remove a task.
4. Click the 🌙 / ☀️ toggle button to switch between dark and light mode.
